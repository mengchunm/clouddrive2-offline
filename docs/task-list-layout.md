# 任务列表窗口布局

## 任务文件详情

- 仅点击已完成任务的名称或名称前方的折叠按钮，才会在任务列表内展开或收起文件；状态、操作和行内空白区域不会触发展开。
- 任务内目录采用位于复选框之后的 IDE 风格目录树；每个目录独立按需读取、展开和收起，多层嵌套不会替换当前文件列表。
- 目录树不显示引导竖线；任务下第一级文件统一缩进一级，后续每层按相同的固定间距递增，折叠箭头与文件图标始终保持一致排列。
- 任务内文件类型不使用状态标签；名称前图标区分目录、媒体、图片、字幕、压缩包、文档、代码、链接及未知文件，状态列仅显示普通文件大小。
- 多个已完成任务可以同时保持展开；每个任务独立维护当前目录、文件列表和加载状态。
- 文件详情按当前目录逐层请求 CloudDrive2，不递归预载整个任务，避免大型任务打开时阻塞界面。
- 文件夹始终排在文件之前，名称采用自然排序；信息列同时显示文件类型与精确大小。
- 文件详情使用与任务主表相同的选择列、名称列、信息列和操作列宽度；不增加水平缩进，仅用淡色背景区分折叠内容。
- 折叠表自身、表格容器和单元格必须保持透明，避免组件库的默认白色表格背景遮住折叠区域底色。
- 文件详情不创建独立的纵向滚动区域，避免滚动条占位压缩名称列并导致状态、操作列错位；纵向滚动统一由任务主表负责。
- 文件详情不渲染第二套表头，直接沿用主表的“名称 / 状态 / 操作”标题；内部状态单元格显示文件类型与大小。
- 展开根目录时不重复显示任务名称；进入子目录后仅显示“返回上一级”，不显示路径标题。
- 内外复选状态采用树形联动：内部未选时父任务未选，部分选中时父任务半选，全部选中时父任务选中；勾选或取消父任务会全选或清空当前目录文件。
- 收起任务只隐藏折叠内容，不清空内部勾选；父任务的半选或全选状态保持不变，再次展开时恢复原目录和选择。
- 折叠区域不提供独立的“删除所选”按钮，内部文件和外层任务统一使用列表顶部批量删除入口；父任务半选时只删除已选内部文件，父任务全选时按整个任务处理。
- 视频与音频显示播放操作；所有普通文件均可在 CloudDrive2 中定位和单独下载。
- 文件操作保持在展开区域内，可播放媒体、在 CloudDrive2 或本地文件管理器中定位、单独下载及删除文件或目录；勾选后支持批量删除。
- 内部文件操作按 CloudDrive2 定位、本地定位、播放、下载、删除排列，与外层任务中相同操作的相对顺序保持一致。
- 网页播放器统一使用圆形播放图标；切换到有独立图标的外部播放器后，内外播放按钮同步显示该播放器图标。
- 播放器菜单仅保留网页播放、PotPlayer、弹弹Play和 Infuse；网页播放由内嵌 ArtPlayer 实现，不再单列重复的 ArtPlayer 选项。

本文记录任务列表悬浮窗口的当前稳定布局规则。后续修改窗口缩放或表格列时，应以本文为准。

## 列布局

- 不显示、也不支持拖动任何内部分隔线。
- 任务选择列固定为 `32px`。
- 名称列占满其余可用宽度，最小宽度为 `140px`，超出内容使用省略号并保留悬浮提示。
- 状态列固定为 `90px`。
- 操作列固定为 `180px`。
- 状态列和操作列始终以最小固定宽度贴在表格右侧，不随窗口宽度变化。

表格最小内容宽度为 `442px`：`32 + 140 + 90 + 180`。面板最小宽度还需包含卡片内边距和滚动条占位。

任务文件折叠表沿用相同的 `442px` 最小内容宽度，内部状态列用于显示文件类型和大小。

## 外部窗口缩放

- 只有窗口右边缘和右上角可以改变窗口宽度。
- 窗口宽度变化时，仅名称列实时伸缩；状态列和操作列的宽度、位置关系保持不变。
- 窗口高度变化时，仅任务列表可见区域实时伸缩，分页保持在内容区底部。
- 浏览器视口缩小时，面板尺寸可以被临时限制；视口恢复后应按照用户最后设定的宽高自动恢复。
- 内部表格不存在可改变外部窗口尺寸的操作。

## 性能约束

- 面板缩放的指针移动通过 `requestAnimationFrame` 合并，每帧最多写入一次窗口尺寸。
- 列布局由浏览器的固定表格布局原生完成，不在缩放期间执行 JavaScript 列宽计算、React 列状态更新或自定义事件联动。
- 表头与表体均使用固定表格布局，表体保留稳定的滚动条占位，避免快速缩放时边界晃动。
- 垂直列表区域使用 CSS 弹性布局，避免根据窗口高度频繁计算分页行数。

## 持久化

- 外部窗口松手后保存窗口宽高和位置。
- 用户展开或收起悬浮窗口时保存当前状态；页面刷新后恢复状态，并继续使用对应的展开或收起位置。
- 任务列表保存当前页码和该页纵向滚动位置；刷新或重新展开后，任务数据渲染完成再恢复滚动位置。
- 如果任务减少导致保存的页码超出范围，自动切换并保存当前最后一页。
- 浏览器视口变化产生的临时显示尺寸不得写入配置或覆盖用户设定尺寸。
- 任务列宽不提供用户配置，也不保存列宽状态。
- 旧版本遗留的列宽配置不再参与渲染，确保升级后直接采用本布局。
