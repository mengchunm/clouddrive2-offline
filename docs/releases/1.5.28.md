# 1.5.28 发布说明

此版本重做任务列表的列布局，彻底移除内部分隔线及其复杂联动。

## 固定右侧列

- 状态列固定为 `90px`。
- 操作列固定为 `180px`。
- 两列始终贴在任务表格右侧，不参与窗口缩放分配。
- 名称列占满选择列与右侧固定列之间的全部剩余空间，最低保留 `140px`。

## 窗口缩放

- 横向缩放窗口时，只有名称列的可显示宽度实时变化。
- 纵向缩放窗口时，只有任务列表的可见高度实时变化，分页仍固定在内容区底部。
- 面板缩放继续使用动画帧合并，表格列由浏览器固定布局直接计算。

## 已移除逻辑

- 表头小分隔线及贯穿表格的蓝色拖动线。
- 内部分隔线拖动、方向判断和列间压缩规则。
- 外部窗口与内部列宽之间的 JavaScript 事件联动。
- 用户列宽和临时显示列宽的读取、更新与持久化。

旧版本已经保存的列宽不会再参与任务表格渲染。
