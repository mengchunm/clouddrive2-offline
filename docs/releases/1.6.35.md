# 1.6.35 发布说明

发布日期：2026-07-24

- 字幕用 libav 工厂与 WebAssembly 已整体内嵌到 `libav-worker.js`，不再通过 `chrome-extension://.../libav/libav-6.9.8.1-default.wasm.wasm` 动态加载。
- 这会直接消除 `wasm streaming compile failed: Failed to fetch`、XMLHttpRequest 加载 WASM 失败以及随后的字幕预读取中断。
- 音频沙箱入口从 ES Module 改为经典 IIFE，确保 opaque-origin 沙箱能够先执行消息监听器并完成 `host-ready` 握手。
- AC-3/E-AC-3 解码器、Worker 和 WASM 仍随扩展提供，不需要安装任何外部程序。

本次只更新 `packages/extension/build`，不生成 ZIP。请在扩展管理页重新加载扩展，并关闭后重新打开原播放页面，使旧 iframe、Worker 和内容脚本全部退出。
