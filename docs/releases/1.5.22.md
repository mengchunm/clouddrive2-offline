# 1.5.22 发布说明

此版本统一分隔线拖动、列压缩和窗口宽度之间的联动规则。

## 分隔线向右

拖动名称/状态分隔线时，依次使用以下空间：

1. 压缩紧邻的状态列，直到状态列达到 `90px`。
2. 压缩最右侧操作列，直到操作列达到保存的最小宽度。
3. 两列均无法继续压缩后，继续拖动会直接扩大悬浮窗口。

拖动状态/操作分隔线时，从操作列压缩开始，然后进入扩窗阶段。窗口最多扩大到浏览器可视区域右边缘。

## 分隔线向左

只缩小分隔线左侧紧邻列，不改变更左侧列；释放的空间由操作列吸收。

## 缩小窗口

窗口宽度减小时，名称列和状态列按照各自剩余的可压缩空间共同缩小。名称列最低 `140px`，状态列最低 `90px`，操作列继续保留最小宽度。三列全部触底后窗口才停止缩小。

窗口尺寸和最终列宽会同时保存，刷新页面后继续使用。
