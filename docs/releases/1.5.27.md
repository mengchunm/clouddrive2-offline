# 1.5.27 发布说明

此版本恢复外部窗口缩放时的全表实时更新，同时保留性能优化。

## 实时更新

横向缩放窗口时，名称列、状态列、操作列、任务行内容和表头会在同一屏幕刷新帧内同步压缩或恢复，不再等待松开鼠标。

## 性能处理

- 指针事件通过 `requestAnimationFrame` 合并，每帧最多执行一次更新。
- 缩放帧内不进行样式写入后的同步尺寸读取，避免强制重排。
- 表头和表体均强制使用固定表格布局。
- 操作列由浏览器原生吸收剩余空间，避免 JavaScript 二次宽度校正。
- 表体使用稳定滚动条占位，防止滚动条出现或消失时改变可用宽度。
- 拖动期间继续关闭表格动画和过渡效果。

用户设定宽度与临时显示宽度仍保持分离，缩小后重新放大会逐步恢复原始列宽。
