# 1.6.33 发布说明

发布日期：2026-07-24

- 修复字幕 Worker 在读取 MKV 文件尾部索引或 Cluster 时，1 MiB 对齐请求超过真实文件末尾并被 Range Host 误判为提前结束的问题。
- Range Host 使用服务端 Content-Range 中的总长度裁剪最后一次读取，并返回准确的实际结束位置；合法 EOF 短块不再触发后台 Base64 代理回退。
- 修复内置 E-AC-3 解码器预热样本末尾多余的 Base64 填充，消除 `atob InvalidCharacterError`。
- 当前分段为空时会在播放器内短暂说明；forced 轨提示“当前时间段没有内容”，普通轨则提示将继续预读。
- 音频回归测试现在会严格解码预热 Base64、验证 Matroska 文件头，并检查 Range Host 保留 EOF 截断逻辑。

目标视频在约 28:10 至 29:10 的实际轨道内容为：`English (forced)` 没有字幕事件，普通 `English`、`English (CC)` 和 `Español` 均有字幕。若需要完整对白，请选择普通 English 或 English (CC)；forced 轨只显示影片标记为强制翻译的少量内容。

本次只更新 `packages/extension/build`，不生成 ZIP。重新加载扩展后必须刷新播放网页，以替换旧内容脚本和 Range Host iframe。
