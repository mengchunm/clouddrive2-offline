# 1.5.29 发布说明

此版本修复浏览器视口恢复后，任务悬浮窗口没有恢复原尺寸的问题。

## 问题原因

旧逻辑在浏览器缩小时，会把受可视区域限制后的面板宽高当作用户设定尺寸保存。浏览器恢复后，原来的较大尺寸已经丢失，因此窗口无法同步恢复。

## 修复方式

- 用户拖动面板边缘结束时，才保存新的期望宽高。
- 浏览器缩小时，仅根据可视区域临时限制当前显示宽高，不修改期望尺寸和持久化配置。
- 浏览器恢复时，重新使用期望宽高进行布局，因此面板会同步恢复。
- 浏览器连续触发的尺寸变化通过 `requestAnimationFrame` 合并处理。

任务表格仍沿用 1.5.28 的布局：状态列和操作列固定贴右，横向变化仅影响名称列。
