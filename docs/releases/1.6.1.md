# 1.6.1

此版本调整任务文件浏览交互，并移除不再需要的本地挂载目录助手。

## 任务文件行内展开

- 点击已完成任务行，在当前任务下方直接展开或收起文件列表。
- 不再增加“查看任务文件”操作按钮，也不再打开独立窗口。
- 子目录仍按层读取，支持返回上一级；视频、音频播放、文件大小、格式分类、CloudDrive2 定位和单文件下载保持不变。
- 快速切换或收起任务时会取消旧结果写入，避免异步请求显示到错误的任务行。

## 本地助手移除

- 设置页删除“打开本地挂载目录”及助手版本状态。
- 删除任务与文件上的本地文件管理器按钮。
- 扩展不再申请 Native Messaging 与下载管理权限，也不再打包安装脚本或 PowerShell Host。
