# 1.6.9 发布说明

## 复用任务主表表头

任务折叠内容不再渲染自己的“文件名 / 信息 / 操作”标题行，直接使用任务主表顶部已有的“名称 / 状态 / 操作”表头。内部状态列显示文件类型和大小，操作列继续提供播放、定位、下载及删除。

## 消除结构性缩进

- 展开行单元格的内边距和边框起始占位被显式清除。
- 折叠容器、内部表格和表格加载容器均强制占满父级宽度，水平外边距固定为零。
- 内外表格统一采用 `32px` 选择列、弹性名称列、`90px` 状态列和 `180px` 操作列。
- 淡色背景继续用于区分折叠内容，不再依赖缩进表达层级。

进入子目录时，顶部仅保留“返回上一级”；勾选文件后仍显示已选择数量和批量删除操作，不再显示路径标题。
