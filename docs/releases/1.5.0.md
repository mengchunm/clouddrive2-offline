# 1.5.0 发布说明

1.5.0 聚焦播放器偏好和全屏交互，并固化此前完成的浏览器扩展字幕方案。

## 主要变化

- 弹幕密度热力图改为默认关闭，可在扩展设置中开启。
- 弹幕透明度、字号、显示区域、速度、防重叠、同步倍速、显示类型和发送样式会跨视频保存。
- 音量、静音、播放速度和画面比例会跨视频保存。
- 字幕轨道、音轨、字幕偏移和全屏状态继续保持视频级状态。
- 全屏和普通模式使用相同控制栏，闲置后自动隐藏，移动鼠标后恢复显示。
- 修复播放器销毁后进度保存定时器未清理的问题。

## 已包含的前序修复

- 默认 CloudDrive2 地址为 `http://localhost:19798`。
- 弹幕默认使用直连模式。
- 远程 MKV ASS/SSA 通过随扩展分发的 libav.js 解封装，并使用 libass 渲染。
- WebVTT 兜底与 libass 实际绘制检测消除了无样式字幕闪烁。
- 可选 Native Messaging Host 支持打开 Windows 本地挂载目录。

详细版本历史见根目录 [`CHANGELOG.md`](../../CHANGELOG.md)。
