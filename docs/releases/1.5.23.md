# 1.5.23 发布说明

此版本修复内部列分隔线无法稳定影响外部窗口宽度的问题。

## 原因

旧逻辑只把悬浮窗右边缘到浏览器右边缘之间的空白计算为可扩展空间。窗口本身靠右时，即使浏览器左侧仍有大量空间，可扩展容量仍会被算成接近零。

## 修复

- 可扩展容量改为“视口最大可用宽度减去当前窗口宽度”。
- 紧邻列和操作列均达到最小宽度后，继续向右拖动蓝线会增大外部窗口。
- 如果窗口右侧空间不足，窗口会同步向左移动，而不是停止扩展。
- 窗口最多扩展到左右各保留 `8px` 的视口范围。
- 松手后同时保存新的窗口宽度、左侧位置和最终列宽。

外部窗口缩小时压缩名称列、状态列的反向联动继续保留。
