# 1.5.25 发布说明

此版本让外部窗口缩放后的内部列宽可以恢复到用户原始设置。

## 两套宽度

- 用户设定宽度：仅通过内部分隔线修改并持久化保存。
- 当前显示宽度：根据外部窗口可用空间临时计算，不覆盖用户设定。

## 缩放行为

- 缩小窗口时，名称列和状态列按照各自可压缩空间逐步缩小。
- 名称列最低 `140px`，状态列最低 `90px`，操作列保留最小宽度。
- 重新放大窗口时，名称列和状态列按相反过程逐步恢复到用户设定宽度与原始分隔线位置。
- 放大超过原始宽度后，额外空间继续由操作列吸收。

松手后只保存外部窗口尺寸，临时列宽不会写入配置。页面刷新或重新展开面板时，会根据保存的窗口尺寸重新计算当前显示宽度。
