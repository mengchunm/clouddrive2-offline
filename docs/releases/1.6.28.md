# 1.6.28 发布说明

发布日期：2026-07-24

## 音频冷启动优化

- 展开任务悬浮窗时，扩展会在隐藏沙箱中提前初始化 E-AC-3/AC-3 解码环境。
- 预热使用扩展包内置的极小静音 E-AC-3 Matroska 样本，无网络请求、无外部程序、无额外安装。
- 选择 MKV 视频后，音轨探测和首段 PCM 解码会立即开始，并与视频缓存地址解析、ArtPlayer 创建和画面加载并行。
- 播放器接管预先生成的 PCM 块，减少首次播放和无缓存场景下的出声等待。

## 行为约束

- 不暂停、不延后视频画面来等待音频，首帧速度保持最高优先级。
- 如果用户在预热完成前立即播放，画面仍会先播放，声音在首个可用解码帧到达后追上当前时间。
- 本次继续使用轻量的 Mediabunny AC-3/E-AC-3 扩展，不引入整套 FFmpeg 播放器。

## 安装验证

1. 在扩展管理页重新加载构建目录。
2. 刷新测试网页并展开任务悬浮窗，让解码器提前预热。
3. 首次打开无缓存的 E-AC-3/AC-3 MKV，确认画面不等待且声音尽可能随播放开始出现。
4. 验证暂停恢复、进度跳转、倍速、音量和静音。
