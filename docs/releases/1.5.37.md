# 1.5.37

发布日期：2026-07-22

## 本地目录安装状态简化

- 删除独立的“启用打开本地挂载目录”开关，避免未安装时无法勾选、安装后状态仍被重置的问题。
- 设置页只保留“下载安装脚本”和“卸载本地助手”两个按钮。
- 成功检测到本地助手时，扩展自动启用任务列表中的本地目录按钮；助手未安装、版本过旧或卸载后自动隐藏。
- 安装完成后的检测与实际打开目录统一复用后台 Native Messaging 持久连接。
- 下载脚本后会持续等待安装完成；用户运行脚本并返回设置页时也会立即重新检测。

安装仍然只写入当前用户的 Chrome/Edge Native Messaging 注册项，不安装 EXE、服务或驱动，也不需要管理员权限。
