# 1.6.26 发布说明

- 修复 E-AC-3/AC-3 已经可以播放，但首次出声和每次跳转后仍需等待约 6～7 秒的问题。
- 原因是旧实现必须等完整十秒音频区间全部解码、下混和传输后，才把 PCM 一次性交给 Web Audio。
- 现在同一个十秒解码任务每积累约 0.5 秒 PCM 就立即流式传给播放器，首块完成即可出声，后续块继续无缝排程。
- 跳转进度或暂停时立即取消沙箱内的旧位置解码，新位置无需等待旧十秒任务结束。
- 保留长解码任务和 Range 缓存，避免简单缩短分段后频繁创建 WASM 解码器、增加网络往返或造成段间断音。
- 增加宿主页、内容脚本桥接和播放器三层流式协议回归检查。
