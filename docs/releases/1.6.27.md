# 1.6.27 发布说明

- 首个 E-AC-3/AC-3 解码帧一生成就立即发送到播放器，不再等待凑齐约 0.5 秒 PCM；后续块继续聚合传输以控制消息开销。
- 启动后的首秒 PCM 按解码帧连续发送，并将 Web Audio 从播放型缓冲切换为交互式低延迟模式，避免首帧直出后出现短暂空隙。
- 播放器暂停时在后台预解码当前位置并暂存 PCM，恢复播放通常可以直接出声。
- 初次自动播放或用户点击早于预热完成时仍坚持画面优先，绝不暂停或延迟视频来等待音频；声音以解码器能够产出的最早时刻对齐当前画面。
- 暂停后立刻恢复时，旧解码取消完成会主动重启当前位置解码，不再额外等待下一次 250ms 检查。
- 增加首帧直出、暂停预热和缓存排程的回归检查。
