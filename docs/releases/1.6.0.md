# 1.6.0

发布日期：2026-07-22

## 任务文件详情

- 完成任务的操作区新增“查看任务文件”按钮。
- 支持逐层进入任务内的文件夹和子目录，并可返回任务根目录；不会一次性递归读取整个任务。
- 文件列表显示名称、类型和大小，并识别视频、音频、图片、字幕、压缩包、文档及其他扩展名。
- 视频和音频文件可直接使用当前默认播放器播放，也能通过右键选择其他播放器。
- 每个文件都能在 CloudDrive2 中定位或单独下载；文件夹也能在 CloudDrive2 中打开。

## Windows 本地定位

- 安装本地助手后，任务文件详情可以在 Windows 文件资源管理器中选中具体文件。
- 文件夹操作仍然直接打开目标目录。
- Native Host 内部协议已升级；若设置页提示助手版本过旧，请重新下载并运行安装脚本。
