# 1.6.38 发布说明

发布日期：2026-07-25

- 字幕首次可用时默认开启，不再固定以“关闭字幕”为默认项。
- 每个视频的字幕选择会长期保存；刷新、CloudDrive2 直链 token 变化以及以后再次播放都会恢复相同轨道。用户选择“关闭字幕”也会被记住。
- MKV 元数据现在识别 default 与 forced 标志。自动选择优先外挂字幕和普通完整字幕，forced 与 CC/SDH 只在用户选择或没有其他轨道时使用。
- 实测目标视频的 `English (forced)` 同时带 default/forced 标志，而 `English` 是完整轨；因此默认会选择 `English`。

`English (forced)` 只在外语、标牌或必须显示的少量对白处出现，绝大多数播放位置没有字幕内容是正常现象。

本次只更新 `packages/extension/build`，不生成 ZIP。重新加载扩展后请关闭旧播放页并重新打开。
