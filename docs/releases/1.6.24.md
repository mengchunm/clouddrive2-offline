# 1.6.24 发布说明

- 修复 Windows Chrome 播放远程 MKV 的 E-AC-3/AC-3 音轨时有画面但没有声音的问题。
- 随扩展内置 Mediabunny AC-3 WebAssembly 解码器，不依赖系统 FFmpeg、播放器或额外安装程序。
- 音频按时间段和 HTTP Range 解码，不会下载完整视频；5.1 音轨在浏览器内下混为立体声。
- 兼容音轨会跟随视频的播放、暂停、拖动进度、倍速、音量和静音，并在时钟漂移时自动重新同步。
- 使用 Manifest V3 沙箱承载 Blob Worker；远程文件读取仍由扩展后台代理，避免网页 CSP 和跨域限制。
