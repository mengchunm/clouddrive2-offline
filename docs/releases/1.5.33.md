# 1.5.33 发布说明

此版本修复扩展重载后的上下文异常，并改善 Native Host 旧版本识别。

## Extension context invalidated

加载已解压扩展后点击“重新加载”，已经打开的网页中仍可能短暂保留旧版内容脚本。旧脚本继续保存窗口、页码或滚动位置时，Chrome 会拒绝访问已经失效的扩展上下文。

现在存储兼容层会：

- 捕获同步抛出的上下文失效异常。
- 处理 `chrome.storage.local.set` 的异步拒绝，避免未捕获 Promise 错误。
- 标记当前上下文失效，停止后续扩展存储访问。
- 继续维护内存缓存，直到用户刷新网页加载新内容脚本。

## Native Host 升级提示

- 设置页通过 `ping.protocol` 区分旧版助手和 v2 助手。
- 检测到旧版时明确提示运行 `clouddrive2-native-host-v2.cmd`。
- 仅重新加载扩展不会更新注册表中的外部助手；必须由用户主动运行新版内置安装脚本一次。

本次检查发现测试电脑注册表仍指向 2026-07-20 安装的 v1 CMD，因此尚未启用 1.5.32 的持久连接加速。
