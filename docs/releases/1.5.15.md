# 1.5.15 发布说明

此版本集中优化窗口缩放和表头分隔线拖动时的流畅度与稳定性。

## 列布局

操作列不再由 JavaScript 尺寸观察器反复计算宽度，而是作为无固定宽度的末列，由浏览器原生填充名称、状态和选择框之外的剩余空间。窗口变化时不会再出现先缩放、后校正导致的分隔线晃动。

## 拖动性能

- 指针事件只记录最新位置，每个浏览器动画帧最多更新一次尺寸。
- 窗口缩放使用已知尺寸直接约束位置，不再在写入宽高后同步读取 DOM 尺寸。
- 列拖动开始时只读取一次可用宽度，移动期间不再反复读取布局。
- 拖动期间关闭表格内部过渡动画，结束后恢复。

## 重复分隔线

Ant Table 会在表体的测量行中再次渲染表头内容。现在隐藏其中重复的拖拽手柄，只保留真正可见表头内的一组分隔线。
