# 1.6.30 发布说明

> 此版本的扩展静态媒体端点在 Chrome 中会返回 40 字节占位内容，已由 1.6.31 的 Range Host 方案替代，请勿单独使用本版本。

发布日期：2026-07-24

## 音频启动性能

- 视频、AC-3/E-AC-3 音频和 libav 字幕现在使用同一个扩展媒体地址与 4 MiB 分块存储。
- 同一文件同一分块正在下载时，其他消费者复用同一个 Promise，不再重复请求 CloudDrive2。
- 缓存地址的数据直接读取为 `ArrayBuffer` 并经 `MessagePort` 转移；只有共享缓存不可用时才回退为后台代理和 Base64 兼容路径。
- 新下载的分块先进入 64 MiB 内存 LRU 并立即返回，IndexedDB 持久化在后台顺序完成，不阻塞首帧和首段 PCM。
- 从任务文件取得准确字节大小后，媒体缓存和音频输入均不再额外发送文件长度探测请求。

## FFmpeg 选择

扩展继续使用 `@mediabunny/ac3` 内置的专用 FFmpeg WebAssembly 解码核心处理 AC-3/E-AC-3。没有把通用 ffmpeg.wasm 命令行核心放入播放热路径：后者需要额外启动大型核心和虚拟文件系统，无法直接改善 CloudDrive2 Range 等待。浏览器原生视频解码和 ArtPlayer 保持不变，避免用 WASM 解码 4K 视频。

本版本不调用本机 FFmpeg，也不增加额外安装步骤。

## 安装

本次只更新固定开发目录 `packages/extension/build`。构建后在扩展管理页点击一次“重新加载”，并刷新测试网页。
