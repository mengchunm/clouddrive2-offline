# 1.6.6 发布说明

## 任务列表本地定位入口

本地助手可用时，已完成且文件仍存在的任务会在任务主列表操作列显示电脑图标。点击后，单文件任务会在 Windows 文件资源管理器中选中文件，目录任务会直接打开对应目录。展开任务后的文件行仍保留相同入口。

## Windows 挂载路径修复

CloudDrive2 的普通 Windows 盘符挂载可能返回 `isMounted=true`、有效 `mountPoint`，但 `localMount=false`。该字段并不表示盘符不可供当前 Windows 访问。路径映射现在以“已挂载且存在挂载目标”为准，例如：

```text
CloudDrive2: /115open/云下载/video.mkv
挂载点:     Z: -> /115open
本地路径:   Z:\云下载\video.mkv
```

新增自动测试覆盖文件定位、目录打开、未挂载过滤及嵌套挂载点优先选择。
