# 1.5.32 发布说明

此版本集中优化“打开本地挂载目录”的响应速度。

## CloudDrive2 查询

- 本地目录功能启用后，在后台预取挂载点。
- 挂载点缓存 5 分钟，并按 CloudDrive2 地址、下载路径和 Token 隔离。
- 点击时使用离线下载路径与任务名称直接构造云端目标并映射到本地路径。
- 只有直接路径不存在时才调用 `findFileByPath` 回退查询，保留移动文件等边界情况的兼容性。

## Native Host v2

- 后台由单次 `sendNativeMessage` 改为持久的 `connectNative` 连接。
- PowerShell Host 可以在同一进程内连续处理多条请求，并通过请求 ID 区分响应。
- 功能启用后会预热 Host，点击按钮时直接复用现有进程。
- CMD 仅在安装或脚本文件缺失时解出内嵌 PowerShell，普通请求不再先启动一个解包 PowerShell。
- `openDirectory` 同时接受文件和目录；文件路径会打开其父目录。
- 后台保留对旧版单消息 Host 的兼容回退，但无法获得完整的常驻加速。

## 升级操作

1. 重新加载 1.5.32 的扩展包。
2. 打开扩展设置。
3. 关闭“启用打开本地挂载目录”，再重新打开。
4. 点击运行新下载的 `clouddrive2-native-host-v2.cmd`。

新版安装仍不包含 EXE、服务或驱动，也不需要管理员权限。
