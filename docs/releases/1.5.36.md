# 1.5.36 发布说明

此版本重新设计本地目录助手的完整安装和启用流程。

## 设置界面

- 独立显示助手状态：检测中、已就绪、未安装、旧版、检测超时或错误。
- 增加始终可见的“下载安装脚本”按钮。
- 下载完成后显示“运行安装脚本”。
- 增加“重新检测”，无需反复切换开关。
- 本地目录状态不再占用普通设置保存提示区域。

## 交互流程

1. 点击“下载安装脚本”。
2. 下载完成后点击“运行安装脚本”。
3. 在系统安装窗口中确认。
4. 设置页自动检测助手，成功后打开功能开关。

开关现在只负责启用或关闭功能。助手尚未安装时打开开关会立即恢复并聚焦下载按钮，不再隐式下载或长时间等待。

## 响应速度

- 单次 Host 检测最多等待约 1.8 秒。
- 下载按钮立即显示进度状态。
- 安装后的检测每 750ms 尝试一次，不阻塞设置页其他控件。
- 关闭功能时注销最多等待 3 秒；即使注销失败，网页功能开关也会先关闭并给出明确错误。

## 命名

- 用户下载的文件固定为 `clouddrive2-native-host-installer.cmd`。
- 浏览器实际调用的专用入口为 `clouddrive2-native-host-run.cmd`。
- 内部协议版本仅用于兼容检测，不再放在下载文件名或用户提示中。
