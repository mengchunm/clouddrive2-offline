# 1.5.1 发布说明

1.5.1 为离线任务列表增加全局搜索。

## 搜索规则

- 无搜索词时继续使用 CloudDrive2 原有的服务端分页，不增加请求量。
- 有搜索词时读取全部任务分页，再在浏览器内筛选和分页。
- 任务名称、磁力链接和 info hash 均可搜索。
- 简体、繁体、大小写和全角字符会先归一化后比较。
- 空格或全角空格用于分隔多个关键词，所有关键词必须同时命中。

例如，输入 `进击 巨人 01` 可以匹配任务名 `進擊的巨人 最終季 第 01 話.mkv`。

简繁转换使用随扩展打包的 `opencc-js`，不访问外部转换服务，也不要求额外安装程序。
