# 1.6.32 发布说明

发布日期：2026-07-24

- MKV 内嵌 SubRip（`S_TEXT/UTF8`）和 WebVTT 字幕接入扩展内 libav.js 分段解封装，不再使用会扫描大量远程分片的旧提取路径。
- Worker 根据 Matroska 字幕包的 PTS 和 duration 生成标准 WebVTT；播放器按当前时间读取约两分钟并在播放或跳转时继续合并后续字幕。
- 当前时间窗没有对白时返回有效空字幕并继续预读，兼容片头和 forced 字幕轨，不再显示“字幕内容不存在”。
- WebVTT 分段内容按开始时间去重排序，内容没有增加时不重复替换字幕轨。
- `test:libav-mkv` 新增 ASS 与 SubRip 双轨 Matroska 回归样本。

本次只更新 `packages/extension/build`。重新加载扩展并刷新原网页后，选择该视频的普通 English/English (CC) 轨即可验证；forced 轨只有在影片实际包含强制字幕的时间点才会显示文字。
